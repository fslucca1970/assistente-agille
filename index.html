2. Como Usar o Assistente

Siga estes passos simples para gerar o seu conteúdo completo (Texto, Hashtags e Imagem):

  • **Passo 1 (Código):** Insira o código rotativo. O status deve mudar para "CORRETO".
  • **Passo 2 (Conteúdo):** Preencha os campos (Tópico, Rede Social, Público-Alvo, Tom de Voz). Descreva a sua ideia de forma detalhada.
  • **Passo 3 (Inspiração):** **(OPCIONAL)** Carregue uma imagem de referência para guiar o estilo e cores da imagem final. Se deixado vazio, a IA gera a imagem apenas pelo texto.
  • **Passo 4 (Gerar):** Clique no botão azul "Gerar Conteúdo".
